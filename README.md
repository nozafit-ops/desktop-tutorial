## ロンドン・チェイス

`tokyo-chase/index.html` は、スコットランドヤード（iOS版）とスクウェア・エニックスの「チェイスチェイス」に着想を得た、ロンドンを舞台にした追跡ボードゲームです。ブラウザで開くだけで遊べます（ビルド不要・オフライン）。

### ルール
- 怪盗X 1人 対 刑事4〜5人（標準4人）。怪盗Xの居場所は秘密で、使った切符の種類だけが公開されます。
- 3手目から1手おき（3・5・7・…・21・23手目）と最後の24手目の移動後に、怪盗Xが姿を現します。隠れているのは長くても1手だけ。24手逃げ切れば怪盗Xの勝ち。
- 乗り物：タクシー（近くの駅）、バス・地下鉄（遠くまで一気に）、水上バス（川沿いと島）、ヘリ（ヘリポートから、着陸地点はランダム）。
- ヘリポートのうち1か所はゲームごとにランダムで「ガス欠」。誰にも知らされず、飛ぼうとして初めてわかる（切符は減り、その場にとどまる）。刑事が引き当てると全員に知れ渡り、怪盗Xが引き当てたときは怪盗Xだけが知る。ガス欠のときはヘリがふわっと浮いて「プスン…」と落ちるアニメーションと「ガス欠！」の見出しで知らせる。
- 切符：刑事はタクシー・バス・地下鉄・水上バスが使い放題（ヘリだけ1枚）。怪盗Xの切符は有限（タクシー16・バス12・地下鉄8・水上バス4、黒チケットは刑事の人数と同じ枚数、2倍移動3枚、ヘリ1枚）。怪盗Xの残りの切符は画面上部の怪盗Xの札に表示。切符が尽きた乗り物には乗れず、動けなくなると怪盗Xの負け。
- 手札：画面の左下にいつも表示（カードの絵と名前、期限、次にカードを引く手）。自分の番で使えるときは金色に光り、カードをタップするとそのまま使える。橋封鎖・駅破壊の対象の駅は赤い丸で示す。移動記録の5・10・17手目のマスには金色の小さなカード印。
- 刑事のキャラ：タイトル画面の「刑事のキャラ」で5人から選ぶと、そのキャラが刑事1（刑事モードのあなた）になり、残りが順に刑事2以降になる。
- 携帯のプルタブ：スマホ幅では画面上部のUIの下にプルタブが付き、タップで上部のUIをまるごと隠したり出したりできる（隠している間はタブに手番だけ表示。設定は次回も保持）。
- 刑事の番に怪盗Xのいる駅へ入った時点で確保（逮捕）。最後の手でも逃げ切りより確保が優先。刑事どうしは同じ駅に重なってよい（怪盗Xは刑事のいる駅には入れない）。
- 相棒：怪盗Xには相棒がいる。最初は怪盗Xから7駅以上離れた場所にいて、誰からも見える。2手ごとに1駅、怪盗Xの本当の居場所へ向かって自動で動く（刑事の隣はなるべく避ける）。怪盗Xが相棒と同じ駅に着くか、相棒が怪盗Xの駅に来た時点で合流成功＝怪盗Xの勝ち。刑事が相棒の駅に入ると相棒を確保し、以後は合流できない。相棒の駒は、選んだ怪盗Xの次のキャラ画像。
- パス：自分の番に「パス」でその場にとどまれる（切符は使わない）。怪盗Xのパスは記録に「休」と残る。2倍移動の途中と、どこへも動けないときはパスできない。
- カード：5・10・17手目に怪盗Xと刑事チームがそれぞれ1枚引いて手札に加える（ハズレあり）。手札は自分の番に画面上の「カード」ボタンから、20手目までいつでも使える。使わなかったカードは20手目を過ぎると失効。CPUは状況を見て使う（刑事が近ければ罠・駅破壊、出現直前に雲隠れ、候補が多ければ追跡犬・聞き込みなど）。
  - 刑事側：橋封鎖（橋を4手のあいだ怪盗Xが通れない）、追跡犬（候補を本当の居場所から2手以内に絞る）、聞き込み（候補を半分に）、ヘリ封鎖（すべてのヘリポートを5手のあいだ閉鎖。誰も飛べない）
  - CPUの刑事は自分の番ならいつでもチームのカードを使う（刑事モードでは、あなたの仲間のCPUもチームの手札を使う）。
  - 怪盗X側：罠（いまの駅に罠。踏んだ刑事は1回休み。刑事には見えない）、雲隠れ（次の目撃情報を1回無効）、駅破壊（2手以内の駅を1つ壊す。黒く塗りつぶされ、最後まで誰も通れない。怪盗X自身も通れない）
- 仲間への指示：刑事モードでは、画面上部の仲間の刑事をタップして行き先の駅を指示できる。仲間はそこへ向かい、周辺で張り込む。
- 作戦ピン：刑事モードで駅を長押し（パソコンは右クリック）すると、仲間をその駅へ向かわせたり、全員で包囲（その駅と周りの駅に1人ずつ割り当て）させたりできる。
- 仲間の狙い：刑事モードでは、CPUの仲間が次に動く駅を点線の矢印と「次は◯◯」で表示（表示どおりに動く）。

### 盤面と操作
- テムズ川が盤面を斜めに横切り、川の中に島が2つ（各島に駅は1つで、水上バスの乗り場。水上バスかヘリでしか行けない）。橋のある場所でだけタクシー・バスが川を渡れます。5つの橋の上には駅（ひし形の台座）があり、橋は両岸の1駅ずつとだけつながる一本道です（バスは橋の上に止まりません）。
- 地下鉄は外周を一周する環状線と、中央を貫く3路線。停車駅を絞って1区間を長くしています。バスはその間を埋める配置です。
- 100駅（橋の上の5駅を含む）の配置と路線はジェネレーターで作り、CPU同士の対戦で釣り合いを調整しています（相棒ルール込みで刑事4人のとき怪盗Xの勝率は約50％、5人で約36％、タクシーは151区間、地下鉄の駅は24）。盤の端で行き止まりになっていたタクシーだけの駅は取り除いています。
- 画面の上部に怪盗Xの札・刑事の切符・手番・移動記録をまとめ、下半分はすべて盤面に使う。
- ドラッグで移動、ピンチ・ホイール・ダブルタップで拡大。光る駅をタップすると切符を選ぶシートが出ます。ヘリは手番表示の「ヘリ」ボタンから。
- 駒は人形型のフィギュア（怪盗Xはシルクハットにマスクとマント、刑事は山高帽に色分けしたコート）。
- 画面の外にいる駒は、画面の縁に方向を示す矢印（駒の顔と色付き）で表示。怪盗Xで遊ぶときは各刑事まで「あと何手」かも出る。タップするとその駒へ移動。
- 見つかり具合の合図：怪盗Xの札に「見失われている／追われている／発見されている」（刑事側の候補駅の数で判定）。刑事の駒の吹き出しは「？」＝見失っている、「！」＝捕捉している。
- 刑事のリアクション：目撃・発見のときは近くの刑事が「いたぞ！」「見つけた！」と叫び、画面中央に「目撃！」「発見！」の見出し。見失うと「見失った…」、候補が絞れると「近いぞ…」、罠にかかると「しまった！罠だ！」、逮捕で「確保ーっ！」＋「逮捕！」、逃げ切られると「逃げられた…」。
- 姿を現す／消える：刑事が怪盗Xの居場所をつかむ（候補が1駅になる）と、刑事側の画面にも怪盗Xの駒が赤く光って現れ、見失うと「…消えた」と煙とともに消える。
- 足跡：怪盗Xの画面では自分の逃走経路に足跡（新しいほど濃い）。刑事側の画面では、発見した場所に足跡と手数が残り、点線でつながる。ゲーム終了後は全員に逃走経路の全体が足跡と手数つきで表示される。
- CPU刑事：最後の目撃から記録された切符をたどって候補駅ごとの「いそうな度合い」を計算し、候補が少ないときは怪盗Xの逃げ先を1手先読みして追い詰める。
- 発見中の合図：怪盗Xが発見されている間は、各刑事の足元から怪盗Xの方向へ赤い矢印が点滅し、居場所には赤い破線の輪。画面外なら端に怪盗Xの方向矢印が点滅。怪盗X（怪盗Xモード）の駒は赤く光って点滅する。
- モード：怪盗Xで遊ぶ（刑事はCPU）／刑事で遊ぶ（刑事1だけを操作し、ほかの刑事と怪盗XはCPU）／みんなで遊ぶ（1台を回すパス&プレイ）。途中経過は自動保存され「つづきから」で再開できます。

### 画像の差し替え
`ART`（`map`・`x`・`d`・`title`）に画像ファイルを指定すると、盤面の背景や人物の肖像を差し替えられます。現在は `map` に `art/london-map.webp` を指定しています。画像を読み込めないときはコードで描いた古地図を使います。

駅・路線は `STATIONS`・`TAXI`・`TUBE`・`BUS`・`BOAT`・`HELI`、ルールの数値は `MAX_MOVES` などの定数で変更できます。
