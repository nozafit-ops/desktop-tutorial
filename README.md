## ロンドン・チェイス

`tokyo-chase/index.html` は、スコットランドヤード（iOS版）とスクウェア・エニックスの「チェイスチェイス」に着想を得た、ロンドンを舞台にした追跡ボードゲームです。ブラウザで開くだけで遊べます（ビルド不要・オフライン）。

### ルール
- 怪盗X 1人 対 刑事3〜5人（標準3人）。怪盗Xの居場所は秘密で、使った切符の種類だけが公開されます。
- 3・8・13・18・24手目の移動後は怪盗Xが姿を現します。24手逃げ切れば怪盗Xの勝ち。
- 乗り物：タクシー（近くの駅）、バス・地下鉄（遠くまで一気に）、水上バス（川沿いと島）、ヘリ（ヘリポートから、着陸地点はランダム）。
- ヘリポートのうち1か所はゲームごとにランダムで「ガス欠」。誰にも知らされず、飛ぼうとして初めてわかる（切符は減り、その場にとどまる）。刑事が引き当てると全員に知れ渡り、怪盗Xが引き当てたときは怪盗Xだけが知る。
- 刑事の切符は有限（タクシー12・バス9・地下鉄5・水上バス3・ヘリ1）。怪盗Xは黒チケット（刑事の人数より1枚少ない）、2倍移動2枚、ヘリ2枚。
- 刑事が怪盗Xのいる駅に入れば逮捕。
- カード：5・10・17手目に怪盗Xと刑事チームがそれぞれ1枚引いてすぐ発動（ハズレあり）。
  - 刑事側：橋封鎖（橋を4手のあいだ怪盗Xが通れない）、追跡犬（候補を本当の居場所から2手以内に絞る）、聞き込み（候補を半分に）、応援要請（全員に切符追加）
  - 怪盗X側：罠（いまの駅に罠。踏んだ刑事は1回休み。刑事には見えない）、雲隠れ（次の目撃情報を1回無効）、駅破壊（2手以内の駅を4手のあいだ刑事が入れない）
- 仲間への指示：刑事モードでは、画面上部の仲間の刑事をタップして行き先の駅を指示できる。仲間はそこへ向かい、周辺で張り込む。
- 作戦ピン：刑事モードで駅を長押し（パソコンは右クリック）すると、仲間をその駅へ向かわせたり、全員で包囲（その駅と周りの駅に1人ずつ割り当て）させたりできる。
- 仲間の狙い：刑事モードでは、CPUの仲間が次に動く駅を点線の矢印と「次は◯◯」で表示（表示どおりに動く）。

### 盤面と操作
- テムズ川が盤面を斜めに横切り、川の中に島が2つ（水上バスかヘリでしか行けない）。橋のある場所でだけタクシー・バスが川を渡れます。5つの橋の上には駅（ひし形の台座）があり、橋は両岸の1駅ずつとだけつながる一本道です（バスは橋の上に止まりません）。
- 地下鉄は外周を一周する環状線と、中央を貫く3路線。停車駅を絞って1区間を長くしています。バスはその間を埋める配置です。
- 111駅（橋の上の5駅を含む）の配置と路線はジェネレーターで作り、CPU同士の対戦で釣り合いを調整しています（刑事3人で怪盗Xの勝率は約46％、タクシーは174区間）。
- 画面の上部に怪盗Xの札・刑事の切符・手番・移動記録をまとめ、下半分はすべて盤面に使う。
- ドラッグで移動、ピンチ・ホイール・ダブルタップで拡大。光る駅をタップすると切符を選ぶシートが出ます。ヘリは手番表示の「ヘリ」ボタンから。
- 駒は人形型のフィギュア（怪盗Xはシルクハットにマスクとマント、刑事は山高帽に色分けしたコート）。
- 画面の外にいる駒は、画面の縁に方向を示す矢印（駒の顔と色付き）で表示。怪盗Xで遊ぶときは各刑事まで「あと何手」かも出る。タップするとその駒へ移動。
- 見つかり具合の合図：怪盗Xの札に「見失われている／追われている／発見されている」（刑事側の候補駅の数で判定）。刑事の駒の吹き出しは「？」＝見失っている、「！」＝捕捉している。
- モード：怪盗Xで遊ぶ（刑事はCPU）／刑事で遊ぶ（刑事1だけを操作し、ほかの刑事と怪盗XはCPU）／みんなで遊ぶ（1台を回すパス&プレイ）。途中経過は自動保存され「つづきから」で再開できます。

### 盤面の画像
- `tokyo-chase/art/london-map.webp`：ゲームで使っている盤面の背景画像（古地図の下絵をもとに描き起こしたもの）
- `tokyo-chase/art/london-background.svg`：背景（古地図）の元データ（ベクター）
- `tokyo-chase/art/london-background.png`：背景画像（3000×1900）
- `tokyo-chase/art/london-board.png`：路線と駅を載せた盤面全体（3000×1900）
- タイトル画面の「古地図の下絵を保存」から、コードで描いた下絵を書き出せます。

### 画像の差し替え
`ART`（`map`・`x`・`d`・`title`）に画像ファイルを指定すると、盤面の背景や人物の肖像を差し替えられます。現在は `map` に `art/london-map.webp` を指定しています。画像を読み込めないときはコードで描いた古地図を使います。

駅・路線は `STATIONS`・`TAXI`・`TUBE`・`BUS`・`BOAT`・`HELI`、ルールの数値は `MAX_MOVES` などの定数で変更できます。
