## ロンドン・チェイス

`tokyo-chase/index.html` は、スコットランドヤード（iOS版）とスクウェア・エニックスの「チェイスチェイス」に着想を得た、ロンドンを舞台にした追跡ボードゲームです。ブラウザで開くだけで遊べます（ビルド不要・オフライン）。

### ルール
- 怪盗X 1人 対 刑事3〜5人（標準5人）。怪盗Xの居場所は秘密で、使った切符（タクシー・バス・地下鉄・黒）だけが公開されます。
- 3・8・13・18・24手目の移動後は怪盗Xが姿を現します。24手逃げ切れば怪盗Xの勝ち。
- 刑事の切符は有限（タクシー12・バス9・地下鉄5）。怪盗Xは黒チケット（刑事の人数と同じ枚数。乗り物を隠す／テムズ川のボートに乗れる）と2倍移動2枚を持っています。
- 刑事が怪盗Xのいる駅に入れば逮捕。

### 盤面と操作
- 実際の緯度経度から配置した96駅。タクシーは近い駅どうし、地下鉄は実在の路線、バスは実在の系統番号に沿ってつないでいます。
- ドラッグで移動、ピンチ・ホイール・ダブルタップで拡大。光る駅をタップすると、使う切符を選ぶシートが出ます。
- モード：怪盗Xで遊ぶ／刑事で遊ぶ（相手はCPU）／みんなで遊ぶ（1台を回すパス&プレイ）。途中経過は自動保存され「つづきから」で再開できます。

### 画像の差し替え
`ART`（`map`・`x`・`d`・`title`）に画像ファイルを指定すると、盤面の背景や人物の肖像を生成画像に置き換えられます。未指定のときはコードで描いた古地図と人物を使います。

駅・路線は `STATIONS`・`TAXI`・`TUBE`・`BUS`・`PIERS`、ルールの数値は `MAX_MOVES` などの定数で変更できます。
