## ロンドン・チェイス

`tokyo-chase/index.html` は、スコットランドヤード（iOS版）とスクウェア・エニックスの「チェイスチェイス」に着想を得た、ロンドンを舞台にした追跡ボードゲームです。ブラウザで開くだけで遊べます（ビルド不要・オフライン）。

### ルール
- 怪盗X 1人 対 刑事3〜5人（標準3人）。怪盗Xの居場所は秘密で、使った切符の種類だけが公開されます。
- 3・8・13・18・24手目の移動後は怪盗Xが姿を現します。24手逃げ切れば怪盗Xの勝ち。
- 乗り物：タクシー（近くの駅）、バス・地下鉄（遠くまで一気に）、水上バス（川沿いと島）、ヘリ（ヘリポートから、着陸地点はランダム）。
- 刑事の切符は有限（タクシー12・バス9・地下鉄5・水上バス3・ヘリ1）。怪盗Xは黒チケット（刑事の人数と同じ枚数）、2倍移動2枚、ヘリ2枚。
- 刑事が怪盗Xのいる駅に入れば逮捕。

### 盤面と操作
- テムズ川が盤面を斜めに横切り、川の中に島が2つ（水上バスかヘリでしか行けない）。橋のある場所でだけタクシー・バスが川を渡れます。
- 地下鉄は外周を一周する環状線と、中央を貫く3路線。停車駅を絞って1区間を長くしています。バスはその間を埋める配置です。
- 106駅の配置と路線はジェネレーターで作り、CPU同士の対戦で釣り合いを調整しています（刑事3人で怪盗Xの勝率は約50％）。
- ドラッグで移動、ピンチ・ホイール・ダブルタップで拡大。光る駅をタップすると切符を選ぶシートが出ます。ヘリは「ヘリで飛ぶ」ボタンから。
- 駒はボードゲームのポーン型（怪盗Xは黒、刑事は色分け）。
- モード：怪盗Xで遊ぶ／刑事で遊ぶ（相手はCPU）／みんなで遊ぶ（1台を回すパス&プレイ）。途中経過は自動保存され「つづきから」で再開できます。

### 画像の差し替え
`ART`（`map`・`x`・`d`・`title`）に画像ファイルを指定すると、盤面の背景や人物の肖像を生成画像に置き換えられます。未指定のときはコードで描いた古地図と人物を使います。

駅・路線は `STATIONS`・`TAXI`・`TUBE`・`BUS`・`BOAT`・`HELI`、ルールの数値は `MAX_MOVES` などの定数で変更できます。
